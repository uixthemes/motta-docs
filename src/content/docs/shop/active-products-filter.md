description: 'Active Products Filter settings and options in the Motta WordPress theme.'
---

![Active Products Filter](../../../assets/images/product-filters-widget.png)

- Go to **Appearance > Widgets** add the Motta - Products Filter widget to the Catalog Sidebar, the Catalog Filter Sidebar.

- The Motta - Products Filter widget works with the catalog page only.
