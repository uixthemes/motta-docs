Thank you for choosing Motta. This page maps out the Getting Started section, from WordPress basics to licensing and support. Use search at the top of the page at any time to jump to an answer, or follow the guides below in order.

Motta runs on WordPress, so you need a working WordPress site before you install the theme. If WordPress isn't set up yet, download it from [wordpress.org](http://wordpress.org). [Before you install](./before-you-install/) covers the setup checks and what's in the Motta package.

## What's in this guide

Follow these pages in order for a complete setup, or jump to the one you need:

1. **[Before you install](./before-you-install/)** — Find WordPress guides, check the server requirements, and see what's in the package you downloaded from ThemeForest.
2. **[Install theme](./install-theme/)** — Download Motta, install it and its plugins, configure image sizes, and import the demo content.
3. **[Theme License](./theme-license/)** — Compare the Regular and Extended licenses, and learn when you need a second one.
4. **[Theme Support](./support/)** — Learn what support covers, how long it lasts, and how to extend it.

Once your site is ready, continue with [Install theme](./install-theme/) to install Motta, set up the required plugins, and import the demo content. The rest of the documentation covers the Customizer, header, shop, product pages, and more.

## Before you start

A short checklist to make installation go smoothly:

- [ ] WordPress is installed and you can access the admin dashboard — see [Installing WordPress](http://codex.wordpress.org/Installing_WordPress).
- [ ] Your server meets the minimum PHP, MySQL, and memory requirements — see [Before you install](./before-you-install/).
- [ ] You've downloaded the Motta package from your ThemeForest account — see [Before you install](./before-you-install/).
- [ ] You know which license you need — see [Theme License](./theme-license/).

## Need help?
